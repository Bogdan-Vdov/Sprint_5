# Автоматизированные тесты для Stellar Burgers

## Описание

Проект содержит автоматизированные тесты для сайта [Stellar Burgers](https://stellarburgers.nomoreparties.site/) с использованием Selenium.

## Тесты покрывают:

- ✅ Регистрацию (успешную и с ошибкой)
- ✅ Вход через разные кнопки
- ✅ Навигацию: Личный кабинет → Конструктор → Выход
- ✅ Проверку разделов в конструкторе: Булки, Соусы, Начинки

## Как запустить

1. Установите зависимости:
   pip install -r requirements.txt
